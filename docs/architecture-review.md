# ERAG 架构与历史审查

审查基线：`dbf05d8`；日期：2026-11-26。范围包括当前全部源码、配置和测试、本地完整的 39 个提交，以及旧检索、生成、入库、评测、下载和提示词实现。GitHub 的全状态 PR 查询未返回记录，本地也没有 merge commit，因此这里以实际提交和代码为证据，不推测不存在的 PR 讨论。未提供论文正文和真实教学评测集，不能把 README 的“thesis-aligned”视为已验证的论文一致性。

## 真正的目标与容易混淆的手段

从项目历史和现有功能推断，底层目标有两个：学生能得到有依据、能追问、能追溯的教学回答；毕业项目能够复现，并解释相对基线的收益。Agent 数量、TCT、摘要、标签、重排和本地部署都是实现手段。

应先区分三类失败：原文没有答案、原文有答案但没有召回、已经召回但回答没有正确利用。第一类需要补资料或拒答；第二类才需要改善检索；第三类需要修复上下文、提示和证据引用。增加检索轮数不能修复扫描 PDF 没有文本，增加回答模型参数也不能修复页码标错。

当前更值得优先解决的缺口是**可信的评测集和实验闭环**。没有固定的语料、人工相关性标注、独立测试集和成本记录，就无法判断复杂流程究竟改善了效果，还是增加了模型调用。此次修改提供测量入口，但不声称已经证明真实语料上的准确率提升，也不把某种架构称为无条件最优。

## 从其他领域借鉴的解决办法

| 当前问题 | 可借鉴的方法 | 本次选择与边界 |
|---|---|---|
| 重建时读到新旧文件混合状态 | 数据库快照、多版本读取 | 不可变快照 + 单一 manifest 原子替换；缓存中的读者继续使用原快照。借鉴的是可见性边界，不是完整数据库的 WAL、fsync 和崩溃恢复保证。[PostgreSQL MVCC](https://www.postgresql.org/docs/15/mvcc-intro.html) |
| 标签误作过滤，排名分数混用 | 搜索系统的召回/排序分层 | 两路各自过阈值、召回候选后合并；向量候选池与 reranker 分数隔离；先重排再截断。原文召回、BM25 + 向量现已加入独立消融，见 [扩大评测](expanded-evaluation.md)。[Contextual Retrieval](https://www.anthropic.com/research/contextual-retrieval) |
| 多轮反馈不断重做相同工作 | 有限状态机、反馈控制的终止条件 | 最大轮数、已检索查询集合、无新证据停止；失败状态与“审查完整”分开。不会仅因超过轮数就宣称成功。 |
| 文件换位置导致评测标签失效 | 构建系统的内容寻址 | 块 ID 从文档内容、分块位置和元数据推导；同内容副本只保留首份来源。源文件迁移不改变 ID，分块规则变更仍需重新核对标签。 |
| 模型服务偶发故障 | 服务容错与可观测性 | 可选规划/重排/审查允许明确降级；向量生成失败不伪造数据。HTTP 连接复用，重试由 SDK 负责，不额外叠加多层重试。 |
| 模块越加越多但收益不明 | 实验设计与消融 | 固定评测样本、索引快照、候选预算、embedding 身份；报告检索指标和延迟。外部服务错误使评测失败，避免把降级结果当成指定实验。 |

这是针对当前仓库规模和约束的取舍，不是跨领域类比本身证明算法有效。尤其是“摘要 + 标签”的加权方式仍需要用教学数据验证。

## 本次具体修复

1. **输入与分块**：长段落有硬上限；先保存旧块再切换页码/章节；章节标题不依赖空行；重叠不跨页、跨章节；CSV 每行携带列名；文本解码失败明确报错。分块使用游标，避免反复复制长文本剩余部分。
2. **索引一致性**：名字与路径校验；失败构建保留旧 manifest；验证块数、ID 唯一性、维数、有限数值、归一化；兼容满足原 embedding 身份的 v2 索引。
3. **检索成本**：多个查询一次批量嵌入；本次问答内复用关键查询向量；缓存知识库且在 manifest 更新后失效；用已有 NumPy 做精确相似度计算，去掉每次搜索重建 FAISS IndexFlatIP 的流程及其强制依赖。没有声称 NumPy 比正确持久化的 FAISS 普遍更快。
4. **证据与反馈**：去重保留最高分与对应查询；章节过滤在取 top-k 之前进行；无匹配章节回退全局；反馈候选重新统一重排；无新证据时避免重复重排/审查。
5. **生成约束**：回答与审查读取同一份完整块组成的上下文；返回来源恰好对应这些块；空证据直接说明不足；空 JSON 回答回退正文。编号越界或缺失时最多进行一次基于同一证据的引用修正，仍失败则告警；条件句、计量对象与上限不得省略。摘要增强遇到 JSON/schema 错误最多修正一次，并记录成功修正数及最终失败块；传输重试仍由 SDK 处理。提示词将文档当作资料，减少把资料内指令当系统指令的风险，但不能据此宣称彻底解决提示注入或幻觉。
6. **历史和 UI**：按对话轮数保留历史，0 真正禁用；HTML 来源不进入模型历史；切换知识库新建独立会话，旧历史仍可恢复；默认知识库名称构建后能正确选中；支持 Gradio 6.x 参数差异。
7. **部署与依赖**：Ark、vLLM、Xinference 分别映射 thinking 参数；显式额外参数优先；区分 Xinference 注册名称 `qwen3` 与调用 UID `qwen3-instruct`；资源下载固定 commit、分目录、记录完整状态。

## 初始实验假设与后续方向

| 优先级 | 实验 / 改进 | 为什么值得做 | 采用条件 |
|---|---|---|---|
| P0 | 教学资料人工标注集，包含单概念、比较、多轮、跨章节、资料不足问题 | 直接测底层目标，识别哪一环失败 | 先确定语料和独立测试集，再调阈值与提示 |
| P1 | 原文向量 vs 摘要向量；逐标签向量 vs 拼接标签 | 摘要可能丢公式、数字和限定条件；当前两个召回通道都依赖压缩表达 | 固定成本下召回提升才采纳；索引格式必须升级，不能混用旧向量 |
| P1 | BM25/字符词项 + 向量，比较加权融合与 RRF | 课程编号、公式符号、罕见术语常需要精确匹配 | 在中文分词/字符粒度下实测；不直接照搬英文检索参数 |
| P1 | TCT 关闭/1轮/3轮；简单问题不做多步规划 | 检验反馈增加的信息是否值得额外调用 | 同时报告正确性、拒答、P95 延迟、模型调用/费用 |
| P2 | Parent-child 检索、页级 OCR/表格结构恢复 | 证据在上下页或图表中时，检索器不能补救解析损失 | 失败样本显示解析与上下文边界是主因时优先 |
| P2 | 持久化 FAISS/HNSW、进程间缓存 | 大规模语料可能超出内存与延迟预算 | 测量 N×D 存储、并发和尾延迟后再引入，不为小型教材库先部署额外服务 |
| P2 | SFT、多个专用 Agent、自动评审模型 | 需要数据与实验才能说明收益 | 不因旧历史中出现过这些目录就恢复；先证明轻量基线不足 |

公开 T2Retrieval 数据可作通用中文检索对照，但不是课堂问题的代理。真实教学质量还需人工检查事实正确性、证据支持关系、表达是否适合学习者及资料不足时的行为。

## 验证边界

离线回归使用确定性假模型和 HTTP 模拟，验证控制流、契约、持久化及指标计算的行为。2026-11-26 已在远程 A800 上运行 Qwen3-8B、Embedding-0.6B 和 Reranker-0.6B，完成真实增强建库、检索及多轮问答，并记录自编课程和公开 T2Retrieval 子集对照。实际收益、失败样例、环境兼容修复和样本边界见 [真实模型实验报告](real-model-results.md)；不能将离线测试通过等同于真实教学准确率提升。

保留的边界包括：快照需离线回收；缓存容量按知识库个数而不是字节限制；上下文预算按字符而非模型 token 计算；引用检查不等于逐句事实蕴含验证；结构分块不等于能理解所有公式和表格的语义分块。

## 聊天工作台与后续实验

界面现采用持久化会话仓库，支持新建、检索历史、重命名、删除与撤销、导出、重试和停止。数据、业务逻辑和展示分开：数据库只存原始问答及结构化来源，渲染时生成安全转义的来源 HTML。停止/删除通过条件更新阻止迟到结果回写；模型 HTTP 请求本身可能继续执行。

扩展实验新增 v4 原文向量，支持 raw 与 BM25/RRF hybrid；旧 v2/v3 索引仍可选择 dual 读取。保留 dual 和 TCT 是为了已有索引兼容与可复现消融，并不意味着这些开关应默认全开。开发与保留测试结果、失败样例和配置取舍集中在 [扩大评测报告](expanded-evaluation.md)。
