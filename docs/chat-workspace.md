# 聊天工作台

运行 `python -m erag.web.ui`，打开 <http://127.0.0.1:7860>。远程部署先建立 SSH 隧道，见 [部署指南](remote-validation.md)。

界面采用薄荷绿侧栏、米白聊天区和圆角输入框。所有知识库与会话管理入口在左侧，右侧专注于问答。窄屏可通过侧栏开关收起工具。

## 日常使用

- **新建对话**：建立独立上下文；历史列表可以切换和按标题搜索。首个问题自动成为标题。
- **对话管理**：重命名、导出 Markdown、删除和撤销最近一次删除。导出保留回答和引用原文。
- **知识库**：选择已有资料库，或选择普通聊天。已有消息时切换知识库会新建对话，原会话仍可在历史中找回。
- **添加知识**：上传 PDF、TXT、Markdown、CSV，填写名称后构建。完成后自动选中新知识库；扫描 PDF 需先做 OCR。
- **检索设置**：重排与 TCT 按会话保存。TCT 是可选补查，会增加模型调用，不能保证答案更好。
- **聊天**：Enter 发送，Shift + Enter 换行。可以复制回答、展开来源、重新生成最后一轮或停止等待。

回答先显示生成状态，完成后一次呈现正文；当前不是逐 token 流式输出。“停止生成”立即恢复输入，并阻止迟到结果写回会话，但底层模型请求可能继续运行到完成。重新生成会替换最后一轮，后续上下文只包含已完成的原始问答，不含来源展示 HTML、错误消息或已停止的轮次。

## 保存与恢复

默认持久化文件位于 `data/`，不进入 Git：

| 文件 | 用途 |
|---|---|
| `chat_history.sqlite3` | 会话、消息、来源和设置 |
| `chat_history.browser-key` | 稳定的浏览器状态加密密钥，服务器重启后仍可恢复历史 |
| `exports/<会话 ID>.md` | 导出的对话 |
| `knowledge_bases/` | 知识库快照 |

位置随 `ERAG_KNOWLEDGE_BASE_ROOT` 的父目录调整。备份前停止 UI，整体备份数据库、密钥与知识库；恢复时保持浏览器站点地址及本地存储。清除浏览器站点数据或更换浏览器，会失去该浏览器关联的会话入口，服务端数据不会自动删除。此功能没有跨浏览器账户同步。

会话按浏览器标识隔离；默认仅监听 `127.0.0.1`，适合个人本地或 SSH 隧道使用。浏览器标识不是公网账户认证，公开部署需要另加身份认证。

## 已验证行为

真实浏览器完成历史恢复、会话切换、新建、重命名、删除与撤销、重试、停止生成；真实 Qwen3 回答可展开教材来源。持久化测试还验证了错误/停止消息不进入模型历史、停止/删除后的迟到请求不会恢复旧消息，以及不同浏览器标识不能读写彼此会话。
