# 课程身份与周期

星桥课程 KX-27 是用于验证教学问答系统的虚构课程。本文件中的规则是该课程唯一的事实依据，不代表真实学校的规定。课程为期八周，前六周开展小组实验，第七周提交项目报告，第八周进行个人答辩。总分为100分，由形成性评价35分、总结性评价45分和同伴互评20分组成。

# 形成性评价

星桥课程的形成性评价发生在第一周至第六周的小组实验过程中，占35分。教师根据实验日志、问题分析和修正记录提供反馈，目的在于帮助学生及时调整学习方法。每次实验日志最多允许修改两次，修改后保留原始版本及反馈记录，不只保留最终结果。形成性评价不使用第八周的答辩表现计分。

# 总结性评价

星桥课程的总结性评价由第七周的项目报告和第八周的个人答辩构成，共45分，其中报告30分、答辩15分。它用于评价阶段结束时的综合掌握程度。报告正式截止后不再允许修改，不能用实验日志或同伴互评分数替代报告和答辩。报告答辩合计不足27分时，需要参加补救学习。

# 同伴互评

同伴互评占20分，安排在第六周结束时进行。每位学生匿名评价另外三位同组成员，从任务贡献、沟通协作两个方面评分，各10分。互评用于记录合作过程，不替代教师评分。若互评分数异常，教师查阅任务记录后复核，不能直接把异常分数计入总分。

# 延迟提交

实验日志迟交24小时以内，扣除该次日志原始得分的10%；超过24小时则该次日志记0分。百分比只作用于该次日志的原始得分，不扣整个课程总分。因已登记的设备故障申请延期时，学生需要在截止前提交工单编号，经教师确认后按批准的新截止时间处理。

# 补救学习

总结性评价不足27分的学生进入补救学习。学生先完成教师指定的薄弱知识练习，再提交一次修订报告。补救后的总结性评价最高计27分，不重新计算已经确定的形成性评价和同伴互评分数。本文件没有公布补救学习的具体日期或报名链接，需等待教师后续通知。

# 数据保护

实验数据中禁止保存学生的身份证号、家庭住址和个人手机号。提交材料用随机实验编号替代姓名，映射表由教师单独保管。学生只能访问本组匿名化数据。实验结束后保留匿名统计结果，并在30天内删除原始个人记录；匿名化不意味着可以公开原始记录。

# 实验环境

星桥课程的实验统一使用 Python 3.11，依赖安装在名称为 starbridge 的独立环境中。代码、配置、随机种子和数据版本写入实验记录。GPU不可用时允许使用CPU完成小规模验证，但应记录设备变化，不能直接把不同硬件上的耗时作为算法优劣的证据。

# 检索评测

检索实验固定使用 Recall@3 和 MRR@3。Recall@3 等于前三个候选中命中的相关知识块数除以该问题全部标注相关知识块数。MRR@3 是前三个候选中首个相关块排名的倒数，前三个均不相关时记0。准确率和召回率不是同一指标，不能互换名称。

# 对照实验

比较检索算法时固定知识库版本、嵌入模型、问题集合、候选预算和硬件。先执行一次不计入统计的预热，再重复三次测量，报告每题结果和总体延迟分布。若模型服务失败，该次实验应标记失败，不能偷偷回退到另一模型并混入原实验统计。阈值只在开发集调整，保留测试集不能用于调参。

# 反馈检索

证据不足时允许将缺失信息改写成新的查询，再进行检索。总检索次数最多三次，包括第一次检索。若反馈查询与之前相同，或者未召回新的知识块，则提前停止。停止仅表示没有继续检索，不代表现有证据已经足够；回答仍需明确指出没有被资料支持的部分。

# 答疑安排

每周二16点至17点进行课程答疑，地点为实训楼B203。学生应提前在课程平台填写问题摘要和已尝试的方法；无需提交个人身份证号或手机号。答疑不是补考，也不改变作业截止时间。关于补救学习的日期，应以教师另行发布的通知为准。
